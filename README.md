# Thailand Grand Tour — Astro

A responsive, editable travel guide for a solo Thailand trip (15 Dec 2026 – 4 Jan 2027).

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Hosting

This project includes a GitHub Actions workflow that builds Astro and deploys the `dist/` directory to GitHub Pages on pushes to `main`. If Pages is not enabled for GitHub Actions automatically, open **Settings → Pages** and select **GitHub Actions** as the source.

## Notes

- Dates and suggested activities are planning notes, not bookings.
- Budget figures are estimates, not live quotes.
- Check event dates, ticket stock, transport schedules, visa rules and tour operators directly before paying.
- Accommodation suggestions are examples to compare; availability and prices vary by date.
